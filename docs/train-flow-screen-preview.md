# Training session 화면 초안 — 2026-10-03

## 범위

`/train/flow-preview`에서 새 화면과 연결 흐름을 확인할 수 있다.
개발 모드 전용이며 실제 로드맵/훈련 진입 경로에는 아직 연결하지 않는다.
실제 Energy 차감, 훈련 결과 보고, 퀴즈/어려움 저장, 해금 판정은 호출하지 않는다.
프리뷰의 상태는 메모리에만 있으며 새로고침하면 초기화된다.

수정 원칙: Level은 내부 진행 단위다. 사용자에게 번호/분량/완료 비율을
보여주지 않고 훈련 행동을 따라오게 한다. Help는 기존 Coach를 그대로 사용한다.
완료 축하는 온보딩의 `PawsDogHero`에 파티 폭죽을 들린 모습으로 구성한다.
강아지는 점프하지 않고, 앞발의 폭죽에서 색종이가 한 번 퍼지는 모션만 사용한다.
마스코트를 누르면 다시 재생되며, 모션 감소 설정에서는 정적인 축하 모습으로 표시한다.

## 필요한 화면과 기존 디자인의 연결

| 화면 | 구성 | 기존 화면과의 관계 |
| --- | --- | --- |
| 준비 | 기존 썸네일·훈련 이름·출처·목적·준비물 + 이번에 할 행동과 Energy 비용 | `LessonHero`, `LessonPreparation` 재사용 |
| 짧은 퀴즈 | 지난 훈련 이름, 문항 진행 바, 2–3개 선택지, 하단 확인/계속 버튼 | 기존 흰 배경과 카드 여백, 연노란 선택 상태, 고정 노란 CTA |
| 퀴즈 피드백 | 같은 화면에 이유 한 문장과 선택적 영상 구간 보기 | 별도 결과 페이지나 점수 화면을 추가하지 않음 |
| 훈련 | 기존 0.6배속 영상, 자막, 타임라인, Continue, 물음표 | 실제 플레이어/자막 컴포넌트 재사용 |
| Help | 기존 Coach 챗봇 | 별도 선택 시트 삭제, 현재 클립 맥락으로 기존 `/train/help` 진입 |
| 회차 완료 | 강아지 마스코트, `Nice work, both of you!`, Continue | 기존 온보딩 마스코트·색상, 번호/진행도 카드 없음 |
| 마지막 완료 | 같은 마스코트, `You did it!`, 영상 해금 안내 | Continue 중심, 선택적인 Rewatch lesson 버튼 |
| 영상 목록 | 행동 이름과 썸네일 목록, 자유 선택 | 번호별 단계 표시 없이 기존 플레이어로 다시보기 |

새 독립 화면은 퀴즈·회차 완료·L5 축하·영상 목록의 4종이다.
준비/영상 화면을 확장하고, Help는 기존 Coach로 연결한다.
별도 퀴즈 소개·퀴즈 점수·재화 정산 페이지는 만들지 않는다.

## 프리뷰에서 확인 가능한 연결

- 첫 회차: 준비 → L1 → L2 → 회차 완료.
- 첫 회차에서 Coach를 연 뒤 목록의 `Continue to next session`:
  준비 → 도움을 요청한 클립에 관한 예시 퀴즈 → L3–L5 → 축하.
- 도움 기록이 없으면 다음 회차는 퀴즈 없이 시작.
- `Preview returning session`: 1문제 예시가 있는 두 번째 회차.
- `Review quiz`: 2문제, 선택/정답/오답 상태를 각각 확인. 이전 어려움이 없으면 이미 진행한 훈련 내용을 복습.
- 피드백 → 해당 영상 구간 보기 → 기존 답변을 유지한 채 퀴즈 복귀.
- L5 축하 → 영상 목록 → 원하는 Level 영상 → 목록.
- 각 화면의 닫기/로드맵 복귀는 현재 프리뷰 목록으로 돌아온다.

선택지와 짧은 설명은 Wait at the Door 전용 예시다. 다른 Lesson에 적용하기 전에
실제 Level/도움말과 문항 매핑을 콘텐츠별로 검수해야 한다.
기존 도움말 대화 기능을 이번 프리뷰에서 교체하지 않았다.
Coach에는 개발 모드에서만 쓰는 클립 맥락 전달을 추가했다.
프리뷰는 Coach를 연 사실만 로컬로 기억한다. 대화/선택의 세부 어려움을
실제 퀴즈 선정에 반영하는 작업은 후속 기능 연결 단계다.

## 이후 기능 연결 순서

1. 회차 정의와 현재 회차 상태에 준비·영상·완료 화면 연결.
2. 회차 시작당 Energy 1회, 중단/재개 위치 및 중복 차감 방지.
3. 실제 물음표/도움 항목을 어려움 기록에 연결. 최종 성공과 어려움 이력 분리.
4. 다음 회차의 문제 선택·첫 응답·피드백 기록 연결.
5. L5 성공 후 축하·영상 해금·로드맵 완료 상태 연결.

원격 DB 변경은 여전히 보류 상태다. 기능 연결과 운영 반영은 다음 작업이다.
