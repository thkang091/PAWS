# Section 6 영상 연결

2026-10-01: 6-1–6-5의 **25개 Level 전체 연결**. Section 5는 계속 보류한다.
기존 준비 화면 → 자동 재생 → Continue 흐름, 0.6배속·무음, 자막 클릭 탐색과
자동 스크롤, 한 번 완료한 영상의 Continue 활성 유지를 그대로 사용한다.

## 연결 구성

숫자는 각 원본 폴더의 클립 번호다. `+`는 별도 시범을 이어 붙인 것이다.

| Lesson | L1 | L2 | L3 | L4 | L5 |
| --- | --- | --- | --- | --- | --- |
| 6-1 Drop It on Cue | 01 | 02 | 03 | 02 + 04 | 04 |
| 6-2 Choose Toys, Not Hands | 01 | 02 | 03 | 01 + 02 + 03 | 01 + 03 |
| 6-3 Redirect Destructive Chewing | 01 | 02 | 02 + 03 | 03 | 01 + 02 + 03 |
| 6-4 Reduce Demand Barking | 01 | 02 + 03 | 03 | 01 + 02 + 03 | 01 + 03 |
| 6-5 Manage Alert Barking | 01 | 01 | 02 + 03 | 03 | 4-3 C06 |

Section 6의 원본 16개와 기존 4-3의 자연 발생 이웃 소리 예시를 재사용한다.
25개 Level에 MP4 24개·poster 24개를 등록한다. 6-5 L1·L2는 같은 파일을 공유한다.
원본은 수정하지 않고 앱의 `assets/training/section-6-*`에 생성했다.

## 승인된 6-3 수정

사용자가 이 대화에서 **영상에 맞춰 6-3 앱 안내 조정**을 승인했다.
`chewingContent.ts`에서 다음 흐름을 앱에만 적용한다.

1. 편안한 공간 마련과 적합한 씹을 것 제공.
2. 연습 물건의 접근을 관리하고 승인된 장난감으로 전환.
3. 전환 후 장난감·씹기 활동 유지.
4. 작은 일상 움직임 중 씹기 활동 유지.
5. 준비 → 전환 → 활동 유지의 전체 관리 루틴.

준비물·안전 안내·Level 설명·도움말 카드·Checkpoint 안내를 일관되게 수정했다.
기존 Level ID·진행도·추가 연습 허용값·Checkpoint 접근 조건은 유지한다.
원격 DB와 커리큘럼 레코드는 변경하지 않았다. 독립적인 두 물건 선택 시험은
이 앱 수정안에서 요구하지 않는다.

## 영상 해석과 제한

- 6-1 L4의 장난감 가치는 보호자가 조절할 조건이며 영상만으로 가치 차이를
  증명하지 않는다. 1-3과 동작은 겹치지만 진행도는 합치지 않는다.
- 6-2의 정지 동작은 피부 접촉 직후의 장면으로 확인된 것이 아니다. 자막은
  접촉이 생기면 적용할 조건부 안내와 정지 연습을 구분한다. L5의 다른 성인
  연습도 기존 성인 시범을 참고하며, 같은 개의 보호자 교대를 촬영한 것이라 주장하지 않는다.
- 6-3의 원본 장식품은 실습용 물건으로 권하지 않는다. 크고 안전한 물건을 사용하도록
  안내한다. 크레이트는 원본의 익숙한 환경 예시이고 필수 장비가 아니다.
- 6-4의 조용한 순간·놀이 중단·놀이 재개는 별도 시범이다. 짖음 직후 중단하는
  한 번의 연속 촬영이나 간식을 줄여 성공한 검증 장면으로 설명하지 않는다.
- 6-5 L2는 기존 쉬운 대안인 짖기 전 보상을 사용한다. L3에는 자극 없이 경로를
  연습하는 장면을 넣었다. L5는 이미 휴식 자리에 있는 개가 실제 이웃 소리 후
  보호자에게 주의를 돌리는 4-3 C06을 사용한다. 통제된 노크를 자연 발생으로 표시하지 않는다.

## 유지보수

- `scripts/training_section6_content.py`: Level별 소스와 행동 자막.
- `scripts/training-section6-sources.json`: 원본 목록, 6-5의 추가 재사용 출처 포함.
- `scripts/build-section6-clips.py`: 기존 생성기 재사용. `--source <Actual> --ffmpeg <실행 파일>`.
- `src/features/train/media/section6*.generated.*`: 클립·자막·소스 등록.
- `src/features/train/media/chewingContent.ts`: 승인된 앱 안내.

영상 길이는 30fps 디코딩 프레임 수로 계산한다. 전체 25개 Level에 대해
생성 영상 프레임 수·자막 범위·파일 존재를 검사했다.

## 검증

- TypeScript 검사 통과.
- 관련 7개 테스트 모음의 303개 사례 통과. 기존 테스트 문자열이 `household`를
  이전 문구로 오인한 부분을 수정하고 해당 모음을 재실행했다.
- 새 클립의 자막 경계·등록·Energy 없는 Level 이어가기·최종 Level 종료,
  6-3 준비물/도움말/Checkpoint 안내와 서버 식별자 보존, Section 5 보류를 포함한다.
- 브라우저의 실제 플레이어에서 25개 Level 모두 파일 길이·0.6배속·무음,
  모든 자막 탐색·재생 재개, 완료 후 Continue, 재시청 후 Continue 유지,
  다음 Level 연결을 확인했다. 브라우저 실행 오류 없음.
- Pixel 7에서 6-3 영상·자막·완료 상태를 확인했다.
