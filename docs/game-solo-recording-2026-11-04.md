# Solo 실제 녹화 연결

2026-11-04. 기존 iPhone 개발 빌드에 포함된 Expo Camera와 Expo Video를 사용한다. 새 네이티브 모듈이나 서버 변경은 없다.

## 흐름

`게임 안내 → Find a clear spot → Start round → 3·2·1 → 실제 녹화 → 영상 확인`

- 모든 Solo 게임에서 준비 제목은 `Find a clear spot`이다. 촬영 중 명령은 게임별 컴포넌트에서 표시한다.
- 카운트다운 중에는 녹화하지 않는다. 끝난 뒤 영상과 음성을 녹화한다.
- Longest Sit 20초, Random Trick Combo 12초, Spot Sprint 8초 제한을 유지한다.
- `End round` 또는 시간 만료로 녹화를 종료한다. 카메라를 유지한 채 파일 생성이 끝나기를 기다린 후 확인 화면으로 바로 이동한다.
- `Preview · not recording`, 휴대폰 거치 안내, 준비 시간 설명 등 카메라의 부가 문구를 제거했다. 필수 명령, 남은 시간, 녹화 표시와 조작 버튼은 유지한다.
- 카메라·마이크 권한을 허용해야 시작할 수 있다. 브라우저에서는 실제 녹화를 제공하지 않으며 휴대폰 앱을 안내한다.

## 파일과 화면 상태

- `soloRoundController.ts`가 카운트다운·녹화·파일 완성 대기를 관리한다. 수동 종료와 시간 만료를 한 번만 처리한다.
- 앱 이탈·카메라 오류·취소는 이전 작업을 무효화한다. 늦게 반환된 파일은 검토 화면을 열지 않고 폐기한다.
- `soloRecording.ts`는 현재 영상 한 개를 임시 보관한다. 경로를 URL에 전달하지 않고 임의의 recording ID로 확인 화면에 연결한다.
- `SoloReviewScreen.tsx`가 실제 파일을 기본 영상 컨트롤로 재생한다. 재촬영·화면 이탈 후 임시 파일을 정리한다. 사진 보관함이나 서버에는 저장하지 않는다.
- 화면의 경기 시간은 녹화 API 호출 기준이다. 실제 영상 길이는 플레이어의 메타데이터로 표시한다. 향후 정밀 AI 채점은 영상 타임스탬프를 사용해야 한다.

## 남은 기능

Submit 이후는 기존 데모 흐름이다. AI 업로드·판독·결과 저장은 아직 연결하지 않았으며 화면에도 이를 표시한다. 게임별 상세 경기 UI 개편, Duel 실제 연결, Tournament 활성화는 이번 범위에 포함하지 않는다.

## 검증

- 타입 검사와 녹화 제어·임시 영상 관리 테스트를 수행했다.
- iOS HTTPS 개발 번들에서 3초 카운트다운과 실제 녹화 코드 반영을 확인했다.
- 실제 iPhone 카메라 입력·마이크 녹음·재생은 기기에서 추가 확인이 필요하다.
