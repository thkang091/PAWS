## 유지보수와 복습 호환성

- `trainingClipFocus.json`이 선택 구간, 자막 수정, 선택 근거를 관리한다.
- 기존 generated source/caption JSON은 취득 이력과 과거 복습 시계의 기준으로 보존한다.
  원본 생성 스크립트를 다시 실행해도 focus 선택은 덮어쓰지 않는다.
- `focusSegments`와 `focusLesson`이 실제 재생 구간 및 자막을 같은 원본 시계로 재계산한다.
  준비/해금 영상/훈련 화면은 같은 catalog getter를 사용한다.
- 첫 예시가 바뀐 1-4 L3/L5, 1-5 L2, 6-2 L4의 포스터도 남긴 실제 영상 프레임으로 교체했다.
- 자막의 `reviewIndex`/`reviewAt`은 과거 ID/시간을 유지한다. 새 자막 순서를 기존 퀴즈 ID로 재사용하지 않는다.
- 저장된 Review quiz의 Watch this moment는 해당 원본의 한 구간만 연다.
  예전에 저장한 문제가 삭제된 예시를 가리켜도 정확한 장면으로 이동한다.
- `20261006151617_focus_training_review_captions.sql`은 14개 level의 출제용 catalog 126행만
  67행으로 교체한다. 전체 709 → 650행. 사용자 진행도·Energy·회차·저장된 문제를 수정하지 않는다.
  실제 PAWS DB 적용 후 전체 catalog의 ID/문구/시간 해시가 앱 seed와 일치함을 확인했다.
