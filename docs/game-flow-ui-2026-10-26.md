# Game 화면 흐름 구현 — 2026-10-26

## 반영한 결정

- 경기가 끝난 후 녹화된 비디오를 AI가 검토한다.
- Solo: Longest Sit, Random Trick Combo, Spot Sprint.
- Duel: PAWS Says, 같은 장소·원격 참가.
- Tournament: Spot Sprint, 같은 장소·원격 참가.
- 이번 단계는 화면과 로컬 상호작용을 구현한다. 실제 녹화·방 연결·업로드·AI 판정·경제 기능은 다음 단계다.

## 스타일

기존 `src/constants/design.ts`를 사용한다. 흰 배경, 짙은 글자, 옅은 노랑/금색 버튼, 얇은 구분선, 24px 좌우 여백, 원형 뒤로가기 버튼을 유지했다. 기존 PAWS 마스코트와 모드 일러스트를 재사용했다. 새 이미지 생성이나 패키지 설치는 없다.

## 연결한 흐름

```text
Game > Challenge
  > Solo 게임 3개 > 게임 안내 > 준비 체크 > 카운트다운
  > 진행 > 영상 확인 > AI 검토 화면 > 예시 결과 / 재촬영 안내

Game > Duel / Tournament
  > 같은 장소 / 원격
  > 방 생성 또는 참가 (QR 화면 / 코드 입력)
  > 대기실 > 게임 선택 > 게임 안내
  > 공통 준비·진행·검토·결과 흐름
```

실제 전송·판정으로 오해하지 않도록 상단에 Preview 안내를 두었다. 예시 방 코드는 PAWS24이며 QR은 레이아웃용 아이콘이다. 실제 초대·스캔을 수행하지 않는다. 참가자 추가는 명시적인 예시 추가 버튼으로만 이뤄진다. 결과 숫자는 예시임을 표시하고 저장하지 않는다.

## 로컬에서 동작하는 것

- 라우트 이동과 뒤로가기, 재도전, Game 홈 복귀.
- 준비 체크에 따른 시작 버튼 활성화, Spot Sprint 목표 선택.
- 같은 장소·원격 선택, 예시 참가 코드 검사, 대기실 준비 상태.
- 3초 카운트다운, 경과 시간, 종료·나가기 확인.
- Combo의 수동 다음 명령, PAWS Says의 시간에 따른 명령 전환.
- 백그라운드로 전환된 프리뷰 라운드의 중단 안내.
- 정상 예시 결과와 불명확 영상의 재시도 화면.

명령 순서, PAWS Says의 5개 명령·8초 간격, 프리뷰 라운드의 120초 상한, Tournament의 4인 예시는 화면 확인용 값이다. 최종 규칙이나 판정 정책으로 확정한 값이 아니다. 명령 전환은 성공 판정이 아니다.

## 이후 연결할 경계

- `gameFlow.ts`: 게임 콘텐츠·규칙 설정. 최종 서버 규칙과 일치시킬 것.
- `GameSessionScreen.tsx`: 카메라 녹화 및 명령 표시 시각 기록.
- `MultiplayerScreens.tsx`: 방·참가자·초대·QR 스캔·준비 상태·공통 시작 시각.
- `GameReviewScreens.tsx`: 실제 클립 재생·업로드·비동기 판정·확정 결과·기록 저장.
- 기존 `src/services/gameService.ts` → `verify-training-video` → Gemini 호출은 확인했다. 새 화면은 해당 서비스의 참가비 차감·보상 함수를 호출하지 않는다.
- 기존 PASS/FAIL/NEEDS_REVIEW 응답을 시간·라운드별 동작·점수로 확장하는 작업은 별도다.
- 기존 `/game/[gameId]` 영상 챌린지와 `/game/shop`은 별도 경로로 유지한다.

## 화면 위치

- `app/game/`의 라우트는 `src/features/game/flow/` 화면 컴포넌트를 연결한다.
- `/game/challenge`, `/game/duel`, `/game/tournament`에서 각각 시작할 수 있다.
- 준비 없이 직접 검토 화면을 열면 새 라운드 시작 안내를 표시한다.

## 검증

- 구현 전 기준 코드와 구현 후 TypeScript 검사 통과.
- 390px 및 360px 폭의 모바일 웹 프리뷰에서 레이아웃 확인.
- Longest Sit의 준비 체크 → 카운트다운 → 종료 → 영상 확인 → AI 검토 → 불명확 결과 → 재도전 확인.
- Combo의 Sit → Paw → Spin 수동 명령 전환과 나가기 확인 모달 확인.
- Duel 원격 참가: 잘못된 코드 안내, PAWS24 예시 코드 참가, 준비 상태·상대 추가에 따른 버튼 활성화, PAWS Says 40초 자동 종료, 예시 대결 결과 확인.
- Tournament 같은 장소 참가: 방 생성, 4인 예시 대기실, Spot Sprint, Platform 선택, 종료·검토·예시 순위 확인.
- 재도전 시 목표 선택 유지, 준비 체크 초기화, 시작 버튼 비활성화 확인.
- 검증 브라우저에서 수집된 console error 없음. 실제 iOS/Android 기기 검증은 수행하지 않았다.
- Android 뒤로가기 리스너는 해당 화면에 포커스가 있을 때만 등록하도록 구현했다.
- 실제 서버·카메라·AI 통합은 이번 검증 범위에 포함하지 않았다.
