# Game 하위 화면 리디자인 — 2026-10-28

## 디자인 기준

기존 Game 메인의 손그림, 흰 배경, 얇은 테두리, 둥근 카드, 노랑·세이지 포인트를 기준으로 Solo·Duel·Tournament 하위 화면을 다시 구성했다.

- 게임 선택·안내: 게임별 그림과 짧은 규칙, 기록 기준을 보여준다.
- 촬영 준비·진행: 반복 마스코트를 없애고 촬영 구도, 준비 체크, 명령, 타이머를 중심에 둔다.
- 영상 검토·판독: 영상 영역과 검토 단계를 구분한다.
- 결과: 기록과 상대 비교·순위가 먼저 보이도록 구성한다.
- 초대·참가·대기실: QR·코드, 참가자, 준비 상태를 중심으로 정리한다.

반복되는 감성 문구와 큰 장식 박스를 줄였다. 공통 프리뷰 설명은 상단 Preview 안내에 모으고, 카메라·예시 결과처럼 오해하기 쉬운 상태에는 짧은 표시를 남겼다.

## Higgsfield 이미지

기존 Game 메인 캡처를 스타일 참조로 사용해 2026-10-27 Higgsfield에서 손그림 4종을 생성했다. 목록·안내에 사용하며 촬영·판독·결과에는 반복 배치하지 않는다.

| 파일 | 장면 |
| --- | --- |
| `longest-sit.png` | 앉은 강아지와 모래시계 |
| `trick-combo.png` | 앞발을 내미는 강아지와 동작 표시 |
| `spot-sprint.png` | 매트 위에 앉은 강아지와 콘 |
| `paws-says.png` | 손으로 명령하는 보호자와 강아지 |

파일 위치는 `assets/images/game/`이며, 생성 모델·설정·작업 ID는 같은 폴더의 `provenance.json`에 기록했다.

## 연결된 흐름

```text
Solo → 게임 선택 → 안내 → 촬영 준비 → 경기 → 영상 검토 → 판독 → 결과 / 재촬영

Duel / Tournament → 같은 장소·원격 선택 → 방 생성·참가
  → 대기실 → 게임 선택 → 공통 준비·경기·검토·결과
```

Solo는 Longest Sit·Random Trick Combo·Spot Sprint, Duel은 PAWS Says, Tournament는 Spot Sprint를 제공한다. `app/game/` 라우트에서 `src/features/game/flow/` 화면을 연결한다.

## 현재 구현 범위

이번 변경은 UI와 로컬 화면 흐름이다. 카메라는 촬영하지 않으며 QR·방 연결·영상 업로드·AI 판정은 미연결 상태다. PAWS24 코드와 참가자·점수·순위는 데모 데이터이며 기록·보상·코인에 반영하지 않는다. 명령 수·간격과 라운드 시간 제한도 프리뷰용 값이다.

- TypeScript 검사 통과.
- 390px·360px 모바일 웹에서 가로 넘침 없이 표시됨을 확인.
