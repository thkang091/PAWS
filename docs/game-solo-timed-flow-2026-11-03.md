# Solo 제한 시간과 제출 흐름

2026-11-03. [전체 화면 카메라 UI](./game-solo-camera-ui-2026-10-28.md)의 후속 변경이다. Solo의 경기 시간을 짧게 정하고, 경기 종료부터 결과 예시까지의 화면 전환을 줄였다. 이번 범위는 UI와 로컬 상태 전환이며 실제 영상 녹화·AI 판독·결과 저장은 아직 연결하지 않았다.

## 현재 흐름

`게임 안내 → 전체 화면 카메라 준비 → 5초 준비 카운트다운 → 경기 → 영상 확인 → Submit → AI review 로딩 예시 → 샘플 결과`

| 게임 | 준비 시간 | 경기 제한 시간 | 결과 예시 |
|---|---:|---:|---:|
| Longest Sit | 5초 | 20초 | 14.2초 |
| Random Trick Combo | 5초 | 12초 | 8.4초 |
| Spot Sprint | 5초 | 8초 | 3.6초 |

5초 준비 카운트다운은 경기 제한 시간에 포함하지 않는다. 카운트다운이 끝난 시점부터 각 게임의 시간이 흐른다. 위 점수는 화면 확인용 고정 예시이며 실제 경기 시간이나 영상에서 계산한 결과가 아니다.

## 촬영 화면

- 준비·카운트다운·경기는 기존처럼 `/game/prepare`의 전체 화면 카메라 안에서 전환한다.
- 준비 화면에 `5 sec to get ready · N sec to play`를 표시한다.
- 경기 중에는 경과 시간 대신 남은 시간을 표시하고, 마지막 3초는 타이머 배경을 조금 강조한다.
- `End round`를 누르거나 제한 시간이 끝나면 즉시 `/game/review`로 이동한다. 기존 `Round ended → Review round` 중간 화면을 제거했다.
- 수동 종료와 자동 종료는 같은 전환 함수를 사용하며, 중복 입력이 두 개의 검토 화면을 열지 않도록 상태를 즉시 변경한다.
- 카운트다운 취소는 준비 화면으로 돌아간다. 경기 중 앱이 백그라운드로 이동하거나 카메라가 준비되지 않으면 중단 상태로 전환한다.
- Spot Sprint의 Mat / Low platform 선택은 확인 화면과 재촬영에서도 유지한다.

제한 시간은 `src/features/game/flow/gameFlow.ts`의 `soloTimeLimitSeconds()`에서 관리한다. 게임 안내와 경기 타이머, 검토 화면의 시간 검증이 같은 값을 사용한다.

## 영상 확인과 제출

`SoloReviewScreen.tsx`가 Solo 전용 확인 화면을 담당한다. 현재는 녹화 파일이 없으므로 영상 영역에 `No recording attached`를 표시한다. 종료 때 전달한 경과 시간과 `Submit / Retake round` 버튼을 보여준다.

- `Submit`: PAWS 색상과 기본 컴포넌트를 사용한 간단한 `AI review` 카드와 로딩바를 표시한다. 3.6초 후 샘플 결과로 자동 이동한다.
- 로딩 화면에는 데모이며 영상이 업로드되지 않는다는 문구를 표시한다. 실제 서버 진행률이나 AI 응답을 나타내지 않는다.
- Solo 경로에서 `View sample result`와 불명확 영상 예시를 선택하는 추가 조작은 제거했다.
- `Retake round`: 같은 게임과 목표를 유지한 채 촬영 준비로 돌아간다.
- 제출 연속 입력은 한 번만 처리한다. 화면 이탈·언마운트·앱 백그라운드 전환 시 대기 타이머를 취소해 나중에 결과 화면으로 갑자기 이동하지 않게 한다.
- 유효한 경과 시간이 없거나 해당 게임의 제한 시간을 넘는 직접 진입은 `No round to review`로 안내한다.

결과 화면은 기존 샘플 화면을 사용한다. `Sample result / Not saved`를 표시하며 `Play again / Back to games`를 제공한다. 개인 최고 기록, 이전 기록, 보상은 갱신하지 않는다.

## 실제 기능 연결과의 경계

휴대폰 카메라 프리뷰와 UI 상태 전환은 동작하지만 녹화 파일 생성, 마이크 녹음, 영상 업로드, AI API 호출, 결과·영상 저장은 미연결이다. 확인 화면으로 전달되는 값도 게임·모드·목표·경과 시간이며 영상 URI나 제출 ID가 아니다. 브라우저는 기존의 명시적인 카메라 자리표시자를 유지한다.

실제 녹화를 연결할 때는 화면 타이머뿐 아니라 녹화 파일과 서버 검증에서도 경기 제한을 일치시켜야 한다. 준비 구간을 영상에 포함할지, 녹화 시작 전후 여유 구간을 얼마나 둘지, `Go` 시점을 영상 시간과 어떻게 맞출지는 [Solo AI 설계안](./game-solo-ai-design-2026-10-28.md)의 미디어 시간 동기화 설계를 따른다. 이번 UI 변경은 그 녹화 시작·종료나 시간 정렬을 구현한 것이 아니다.

Duel의 기존 준비·경기·검토 흐름은 유지했다. Tournament 잠금도 그대로다.
